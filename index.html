    How to read it

    Disc area is the share of the window spent in that behaviour. The size key under the figure shows 10% and 25%.
    Clock ring: one bar per 5-minute slice, read like a clock: 0′ at the top, then clockwise.
    Arrow A → B: B came right after A. Thickness = transitions per learner. Click a disc to highlight only its links.
    Loop: the behaviour followed itself.
    EarlyArrow colour = minute of sessionLate

    About this tool

    Everything runs in your browser. The log you load is never uploaded. The page remembers your last log on this device so it is there next time; use pseudonymous learner IDs and clear it when you are done with real student data.

    The link logic is adapted from ordered network analysis (ONA). This is a descriptive, ONA-inspired figure, not a full ONA: it does not normalise, reduce dimensions or test differences between groups. For statistical comparisons, run ONA itself.
