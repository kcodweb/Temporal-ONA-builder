Temporal ONA builderONA-inspired network of time and order

For coded learning and activity logs

See how long, when and in what order

Upload an episode log and get one network that shows how much time learners spent in each behaviour, when in the session it happened, what followed what, and when each link happened. It works with any coded episodes, such as self-regulated learning, collaboration or clickstream events, over minutes, hours or days.

Run it on your own computer

Download the tool as a single HTML file and open it in any browser. It works without an internet connection and without installing anything; only the font falls back to your system font.

Nothing you load leaves your device. The page only fetches its font from Google Fonts. The optional AI reading sends a numeric summary of the figure, never your rows or learner IDs, and only when you ask. Use pseudonymous learner IDs with real student data.

    About this tool
    
  
    The Temporal ONA builder turns a coded episode log, such as self-regulated learning codes, collaboration moves or clickstream events, into one figure that shows how long learners spent in each behaviour, when in the session it happened, what followed what, and when each link happened.
    
  
    The link logic is adapted from ordered network analysis (ONA). This is a descriptive, ONA-inspired figure, not a full ONA: it does not normalise, reduce dimensions or test differences between groups. For statistical comparisons, run ONA itself.
    
  
    Your data
    
  
    Everything runs in your browser and the log you load is never uploaded. The page remembers your last log on this device so it is there next time; use pseudonymous learner IDs and clear it when you are done with real student data. The AI reading is off until you use it, and then sends only the numeric summary shown under “See exactly what will be sent”.
